# 🚀 100 Formulários HTML, CSS e JavaScript — Do Básico ao Profissional

Vamos montar uma coleção com **100 projetos de formulários prontos para estudar, executar, modificar e adicionar ao seu portfólio frontend**.

A ideia é aprender progressivamente, começando com formulários HTML simples e avançando até interfaces profissionais com validação, máscaras, campos dinâmicos, integração com APIs e recursos modernos de JavaScript.

**Importante:** para que você consiga estudar cada projeto, vamos utilizar código funcional, organizado e pronto para executar no navegador. Quando um formulário precisar de backend, banco de dados ou API, indicarei o que é necessário para torná-lo uma aplicação completa.

# 💻 Vamos começar: Projeto 1 de 100

## Formulário de contato simples

Este primeiro projeto utiliza apenas HTML e CSS.

Você vai aprender a:
- Estruturar um formulário com a tag `<form>`.
- Criar campos com `<input>` e `<textarea>`.
- Associar etiquetas aos campos com `<label>`.
- Utilizar atributos como `required`, `type` e `placeholder`.
- Estilizar o formulário com CSS.
- Criar um layout responsivo.

### 1. Estrutura dos arquivos

Crie uma pasta chamada `projeto-01-formulario-contato` com esta estrutura:

```text
projeto-01-formulario-contato/
├── index.html
└── style.css
```

### 2. Código completo do HTML

Crie o arquivo `index.html`:

```html
<!DOCTYPE html>
<html lang="pt-BR">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <meta
        name="description"
        content="Entre em contato conosco utilizando nosso formulário."
    >

    <title>Formulário de Contato</title>

    <link rel="stylesheet" href="style.css">
</head>

<body>

    <main class="container">

        <section class="contact-card">

            <header class="contact-header">
                <h1>Entre em contato</h1>

                <p>
                    Preencha o formulário abaixo.
                    Responderemos assim que possível.
                </p>
            </header>

            <form action="#" method="post">

                <div class="form-group">
                    <label for="nome">Nome completo</label>

                    <input
                        type="text"
                        id="nome"
                        name="nome"
                        placeholder="Digite seu nome"
                        autocomplete="name"
                        required
                    >
                </div>

                <div class="form-group">
                    <label for="email">E-mail</label>

                    <input
                        type="email"
                        id="email"
                        name="email"
                        placeholder="seuemail@exemplo.com"
                        autocomplete="email"
                        required
                    >
                </div>

                <div class="form-group">
                    <label for="assunto">Assunto</label>

                    <input
                        type="text"
                        id="assunto"
                        name="assunto"
                        placeholder="Qual é o assunto?"
                        required
                    >
                </div>

                <div class="form-group">
                    <label for="mensagem">Mensagem</label>

                    <textarea
                        id="mensagem"
                        name="mensagem"
                        rows="5"
                        placeholder="Escreva sua mensagem..."
                        required
                    ></textarea>
                </div>

                <button type="submit">
                    Enviar mensagem
                </button>

            </form>

        </section>

    </main>

</body>

</html>
```

## 4. Como executar o projeto

1. Crie a pasta do projeto.
2. Salve os códigos nos arquivos `index.html` e `style.css`.
3. Abra o arquivo `index.html` no navegador.
4. Preencha os campos e tente enviar o formulário.

O navegador verificará automaticamente se os campos obrigatórios foram preenchidos e se o e-mail tem um formato válido.

**Atenção:** o formulário ainda não envia mensagens de verdade. Como o atributo `action` está definido como `#`, não existe um servidor recebendo os dados. A finalidade deste primeiro projeto é estudar a estrutura e o visual.

## 5. O que você aprendeu?

| Recurso | Finalidade |
|---|---|
| `<form>` | Define o formulário |
| `<label>` | Identifica um campo |
| `<input type="text">` | Recebe texto |
| `<input type="email">` | Recebe um endereço de e-mail |
| `<textarea>` | Recebe mensagens maiores |
| `required` | Torna o preenchimento obrigatório |
| `placeholder` | Exibe uma orientação dentro do campo |
| `:focus` | Estiliza o campo quando selecionado |
| `:hover` | Estiliza o botão quando o mouse está sobre ele |
| `@media` | Adapta o layout a telas menores |

### Seu desafio

Antes de avançar para o Projeto 2, experimente fazer estas modificações:

1. Adicione um campo para telefone.
2. Acrescente um campo de seleção de assunto com `<select>`.
3. Mude a cor do botão.
4. Altere a largura máxima do formulário.
5. Faça o formulário funcionar corretamente em uma tela de celular.
